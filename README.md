- 🔧 **RPA:** UiPath — form automation, data extraction, Excel/report generation

- 🤖 **AI Integration:** Connecting LLMs (Claude, GPT-4o, Grok) into real business workflows for classification, extraction, and generation tasks
- 📊 **Data Handling:** Google Sheets, Excel automation, structured data pipelines
